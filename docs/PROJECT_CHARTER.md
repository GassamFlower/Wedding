## 1. 项目概述

### 1.1 一句话定义

**大喜的日子** 是一个 AI 驱动的婚礼场景设计协作平台——策划师上传场地照片，AI 生成效果图；新人用自然语言描述梦想婚礼，AI 输出可视化方案和透明报价。

### 1.2 业务背景

| 项目 | 说明 |
|------|------|
| 线下业务 | 婚礼场景策划 + 道具租赁 + 企业活动（已实际运营） |
| 团队规模 | 5人（策划部 / 工程部 / 婚礼管家 / AI技术岗 / 现场） |
| 覆盖区域 | 武汉市区 + 湖北二三线城市 |
| 当前阶段 | 已盈利，需 3-5 万过桥资金解决押金瓶颈 |
| 获客渠道 | 小红书内容获客（主力）+ 老客户转介绍 + 酒店/花艺师推荐 |

### 1.3 核心问题

传统婚礼策划行业从"获客→设计→报价→执行"全链路靠手工：
- 策划师反复跑场地、手写方案、靠经验估道具量
- 新人看不到效果图，反复沟通成本高
- 报价靠拍脑袋，利润不可控
- 市面无专属工具，通用 CRUD 系统无法服务设计环节

### 1.4 产品定位

| 维度 | 定位 |
|------|------|
| 核心价值 | 帮策划师快速出方案出效果图、控制成本利润 |
| 目标用户 | 策划师（内部效率工具）+ 准新人（服务体验升级） |
| 产品形态 | 微信小程序（双角色：新人端 3 Tab + 策划师端 4 Tab） |
| 差异化 | AI 设计对话 + 场景效果图生成 + 成本利润引擎 + 方案一键转订单 |
| 设计语言 | 轻复古·奶油风 暖白基底 + 香槟金点缀 |

## 2. 产品架构

### 2.1 新人端（默认入口，3 Tab）

```
Tab 1 首页 — AI 设计对话
  ├── 多轮对话收集需求（风格/预算/人数/场地）

  ├── 手动案例灵感入口：输入栏上方横条"✨ 找灵感"
  ├── 需求完整 → 一键生成方案
  ├── 方案展示 + 客户友好报价（4项简洁大类）
  └── 历史对话管理

Tab 2 案例 — 精选案例馆
  ├── 瀑布流展示精选婚礼案例（新中式/韩式/森系/法式/现代/户外）
  ├── 风格筛选 + 案例数量统计
  └── 底部 CTA 引导至 AI 设计对话

Tab 3 我的
  ├── 我的收藏（案例）
  ├── 咨询记录
  ├── 婚礼倒计时 + 筹备清单 + 预算计算器
  └── 策划师工作台入口（隐藏/需验证邀请码 Daxi2026）
```

### 2.2 策划师端（隐藏入口，4 Tab）

```
Tab 1 工作台 — Dashboard

  └── 快捷操作

  ├── 按状态分组：进行中 / 待确认 / 已完成
```

## 6. 定价与利润模型

### 6.1 核心原则

- **客户看到 4 大类**：场景设计与道具 / 花艺设计 / 策划与执行服务 / 运输与物流
- **策划师看到全部明细**：每项道具折旧单价 × 数量、每种花材采购底价、每类人工 × 人天、消耗品/保险/损耗准备金/AI 平台成本、**利润金额和百分比**
- **建议报价区间**：最低（成本 × 1.20）/ 标准 / 品质（成本 × 1.55）

### 6.2 成本计算依据（2026 年武汉市场行情）

**道具折旧**：自有道具按使用寿命分摊（如竹节椅 ¥3/次，桁架 ¥150/次）
**人工日薪**：策划师 ¥800 / 工程主管 ¥600 / 工人 ¥400 / 花艺师 ¥600 / 管家 ¥500
**运输**：按道具总量估算车型（小面 ¥150 / 中面 ¥300 / 大车 ¥600）× 2 趟
**平台**：LLM Token ≈ ¥0.5/次 + 图片生成 ≈ ¥2/次 + 云服务 ≈ ¥0.5/次
**其他**：消耗品 2% + 保险 ¥200 + 意外损耗准备金 3%

## 10. 商业模式

```
收入来源：
  ├── 主营业务：婚礼场景策划 + 道具租赁（线下，已盈利）
  ├── AI 会员费：
  │     Pro ¥99/月 × 独立策划师
  │     Studio ¥299/月 × 工作室
  └── 远期：AI 场景模板出售、线上策划咨询

成本结构：
  ├── 道具采购 + 折旧
  ├── 人工（5人团队）
  ├── 运输（货拉拉等）
  ├── AI API 调用（DeepSeek + 图片生成）
  └── 云服务（微信云开发按量计费）

盈利策略：
  └── 每单婚礼方案通过成本引擎自动嵌入利润（默认 20-35%）
  └── AI 会员费覆盖 AI 技术成本
```
