依赖方向规则

模块间通过接口通信，禁止循环依赖

┌─────────────────────────────────────┐
│         页面层 (pages/)              │
│  可依赖任意模块，负责组合和路由        │
└─────────────────────────────────────┘
                ↓
┌─────────────────────────────────────┐
│         业务模块层 (modules/)        │
│  模块间通过接口通信，禁止循环依赖      │
└─────────────────────────────────────┘
                ↓
┌─────────────────────────────────────┐
│         共享层 (shared)              │
│  类型定义、工具函数、常量             │
└─────────────────────────────────────┘

组件复用规则

优先复用，禁止重复造轮子

组件类型 存放位置 复用规则
UI 基础组件 shared/components/ 三端共享，纯样式，无业务逻辑
业务组件 modules/[module]/components/ 模块专属，不跨模块复用
跨端业务组件 shared/components/business/ 需抽象为纯逻辑，无端特有标签

状态管理规范

状态就近管理，避免全局污染

状态类型 管理方式 示例
UI 状态 组件内 useState 弹窗开关、表单输入
模块状态 模块 stores/ (Zustand) 对话上下文、订单列表
全局状态 shared/stores/ 用户信息、角色权限

API 请求规范

统一使用 TanStack Query，禁止直接调用原生 API

// ✅ 正确：使用 TanStack Query
import { useQuery } from '@tanstack/react-query';

export const useCases = (filters) => {
  return useQuery({
    queryKey: ['cases', filters],
    queryFn: () => caseApi.getCases(filters),
  });
};

// ❌ 错误：在组件内直接调用
useEffect(() => {
  wx.request({  // 禁止！
    url: '/api/cases',
  });
}, []);

模块边界检查清单

开发新模块时，确保遵循以下规则

单一职责
模块只负责一个业务领域
统一目录结构
遵循 components/hooks/services/stores/types/pages 结构
依赖方向
只能依赖共享层，不能循环依赖其他模块
组件复用
优先使用 shared/components 中的组件
状态管理
模块状态放在模块内，全局状态放在共享层
API 请求
统一使用 TanStack Query，禁止直接调用原生 API
类型定义
模块类型放在 modules/[module]/types/，共享类型放在 shared/types/
导出入口
每个模块必须有 index.ts 作为统一导出入口

界面元素统一规范（跨端对照表）

四个核心元素的"原子级"规范，确保手机和电脑识别度一致

界面元素 小程序 (Taro) Web 官网 (Next.js) 管理后台 (Ant Design Pro) 统一规范细节
按钮 圆角 --radius-md，主按钮渐变金，点击缩放 0.95 同左，增加 hover 轻微上浮阴影 覆盖 AntD 默认变量：border-radius 改为 10px，主按钮 primary-color 改为 #D4AF37 高度统一：大号 44px，中号 36px。禁用态统一为 #F5E6C8 背景
输入框 下划线或描边风格，聚焦边框变金 同左，带极淡内阴影 覆盖 @input-border-color 为 #F5E6C8，@input-height-base 为 36px 占位符颜色统一为 --color-text-hint (#BFBFBF)，圆角 --radius-md

Layer 1：UI 基础组件

纯样式，无业务逻辑

  • 使用 React + CSS Modules 或 Styled-Components
  • 只依赖 CSS 变量
  • 封装 <Button />, <Input />, <Card />, <Modal />
  • 小程序端用 View/Text 封装，Web 端用 div/span 封装
// packages/shared/components/Button.tsx
export const Button = ({ variant, size, children }) => (
  <button className={`btn btn-${variant} btn-${size}`}>
    {children}
  </button>
);

Layer 2：框架桥接层

适配层，让各框架"穿上"设计变量

  • 管理后台：AntD ConfigProvider 全局覆盖变量
  • 小程序：Taro 直接引用 Layer 1，配合 postcss-pxtransform 处理单位转换
  • Web 官网：Next.js 直接使用 Layer 1，配合 Tailwind CSS
// packages/admin/src/App.tsx
<ConfigProvider theme={themeConfig}>
  <YourApp />
</ConfigProvider>

Layer 3：业务组件

跨端复用，纯逻辑 + props

  • 例如 <CostProfitPanel />（成本利润引擎）
  • 例如 <AIChatInput />（AI 对话输入框）
  • 不包含任何端特有标签（如 window 或 wx.）
  • 只接收 props 传出数据
  • 小程序用 Taro 渲染，官网/后台用 React 渲染
// packages/shared/components/CostProfitPanel.tsx
export const CostProfitPanel = ({
  totalCost, profit, profitRate
}) => (
  <Card>
    <div className="cost-profit-panel">
      {/* 纯逻辑，无端特有标签 */}
    </div>
  </Card>
);
